# Калории

Простой дневник калорий в виде PWA: без аккаунтов, рекламы и лишних функций. Данные хранятся только в браузере (IndexedDB).

- **Дневник** — записи за день, остаток до цели, белки/жиры/углеводы.
- **Продукты** — личный справочник. КБЖУ вводится с этикетки на 100 г или на порцию.
- **Рецепты** — соберите блюдо из сырых продуктов, укажите вес готового и получите КБЖУ на 100 г. Рецепт ищется как обычный продукт.
- **Сканер штрихкодов** — камера или ввод цифр. Сначала ищет в вашем справочнике, затем в [Open Food Facts](https://world.openfoodfacts.org) и подставляет КБЖУ (их стоит сверить с этикеткой).
- **Вес** — запись веса и график за месяц, 3 месяца или всё время. Последний вес обновляет расчёт цели.
- **Цель** — расчёт по формуле Миффлина — Сан-Жеора с дефицитом, можно задать вручную. Резервная копия: экспорт/импорт JSON.

## Разработка

```bash
npm install
npm run dev      # dev-сервер
npm test         # тесты расчётов и базы
npm run build    # сборка в dist/
npm run preview  # проверка production-сборки с service worker
```

## Публикация

Workflow `.github/workflows/deploy.yml` публикует сборку на GitHub Pages при пуше в `main`. В настройках репозитория: Settings → Pages → Source: GitHub Actions.

После открытия сайта на телефоне выберите «Установить приложение» (Android/Chrome) или «Поделиться → На экран „Домой“» (iOS/Safari).
